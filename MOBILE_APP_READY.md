# 📱 Мобильное приложение для сотрудников - ГОТОВО!

Создана полная структура мобильного приложения на React Native (Expo) для сотрудников выездной медицинской помощи "АлкоСпас".

## ✅ Что создано

### Структура проекта (папка `mobile/`)

```
mobile/
├── src/
│   ├── api/
│   │   └── index.ts              # API клиент для Google Sheets
│   ├── screens/
│   │   ├── LoginScreen.tsx       # Экран авторизации
│   │   ├── HomeScreen.tsx        # Главный экран с меню
│   │   ├── ExpenseSheetScreen.tsx # Создание листа расхода
│   │   ├── MessagesScreen.tsx    # Чат с руководителем
│   │   ├── AnnouncementsScreen.tsx # Объявления
│   │   ├── ProfileScreen.tsx     # Профиль сотрудника
│   │   └── SetupScreen.tsx       # Настройка подключения
│   ├── store/
│   │   ├── authStore.ts          # Хранилище авторизации (Zustand)
│   │   └── dataStore.ts          # Хранилище данных (Zustand)
│   └── types/
│       └── index.ts              # TypeScript типы
├── App.tsx                       # Главный компонент
├── app.json                      # Конфигурация Expo
├── package.json                  # Зависимости
├── tsconfig.json                 # Настройки TypeScript
├── babel.config.js               # Конфигурация Babel
├── .gitignore                    # Исключения для Git
├── README.md                     # Подробная документация
└── APPS_SCRIPT_UPDATE.md         # Инструкция по обновлению Apps Script
```

## 🎯 Функционал приложения

### ✅ Реализовано:

1. **Авторизация**
   - Вход по персональному номеру и паролю
   - Проверка статуса сотрудника (активен/заблокирован/уволен)
   - Безопасное хранение сессии

2. **Главный экран**
   - Статус смены (открыта/закрыта)
   - Кнопка управления сменой
   - Быстрый доступ ко всем функциям
   - Счетчики непрочитанных сообщений и объявлений

3. **Лист расхода**
   - Создание нового листа расхода
   - Выбор пациента (ФИО, дата рождения)
   - Выбор категории выезда
   - Добавление препаратов из номенклатуры
   - Автоматический расчет суммы
   - Сохранение и отправка руководителю

4. **Сообщения**
   - Чат с руководителем
   - История сообщений
   - Отправка новых сообщений

5. **Объявления**
   - Список активных объявлений
   - Просмотр деталей

6. **Профиль**
   - Личная информация
   - Статус сотрудника
   - Выход из аккаунта

7. **Настройка подключения**
   - Ввод URL Google Apps Script
   - Проверка подключения

## 🚀 Как использовать

### Шаг 1: Создание нового репозитория

```bash
# Создайте новый репозиторий на GitHub
# Например: alkospas-employee-mobile

# Клонируйте его
git clone https://github.com/your-username/alkospas-employee-mobile.git
cd alkospas-employee-mobile
```

### Шаг 2: Копирование файлов

Скопируйте все файлы из папки `mobile/` в новый репозиторий:

**Вариант 1: Через файловый менеджер**
- Откройте папку `mobile/`
- Выделите все файлы (Ctrl+A)
- Скопируйте (Ctrl+C)
- Вставьте в новый репозиторий (Ctrl+V)

**Вариант 2: Через командную строку**
```bash
# Если вы в корне текущего проекта
cp -r mobile/* /path/to/new-repo/
cp mobile/.gitignore /path/to/new-repo/
```

### Шаг 3: Обновление Google Apps Script

Откройте файл `APPS_SCRIPT_UPDATE.md` и следуйте инструкциям:

1. Откройте Google Sheets с базой данных
2. Перейдите в **Расширения → Apps Script**
3. Добавьте новые функции:
   - `authenticateEmployee()` - авторизация сотрудника
   - `getEmployeeExpenseSheets()` - получение листов расхода
   - `getEmployeeMessages()` - получение сообщений
4. Обновите функцию `doGet()` - добавьте новые case
5. Сохраните и разверните новую версию

### Шаг 4: Установка зависимостей

```bash
cd /path/to/new-repo
npm install
```

### Шаг 5: Добавление ресурсов

Создайте папку `assets/` и добавьте:

```bash
mkdir assets

# Скопируйте логотип из основного проекта
cp /path/to/web-app/public/logo.png assets/

# Или создайте свои ресурсы:
# - logo.png (512x512px) - для экрана входа
# - icon.png (1024x1024px) - иконка приложения
# - adaptive-icon.png (1024x1024px) - для Android
# - splash.png (1284x2778px) - заставка
```

### Шаг 6: Запуск приложения

```bash
npm start
```

Отсканируйте QR-код в приложении **Expo Go** на вашем устройстве.

### Шаг 7: Настройка

1. Введите URL вашего Google Apps Script
2. Нажмите "Подключиться"
3. Введите персональный номер и пароль
4. Нажмите "Войти"

## 📱 Тестирование

### На реальном устройстве

1. Установите **Expo Go** из App Store или Google Play
2. Запустите приложение: `npm start`
3. Отсканируйте QR-код

### На эмуляторе

**Android:**
```bash
npm run android
```

**iOS (только macOS):**
```bash
npm run ios
```

## 📦 Сборка для публикации

### Android APK

```bash
expo build:android -t apk
```

После сборки получите ссылку для скачивания APK.

### iOS (только macOS)

```bash
expo build:ios
```

Для публикации в App Store потребуется:
- Apple Developer Account ($99/год)
- Mac с Xcode
- Сертификаты и профили
