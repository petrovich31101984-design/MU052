# Папка для ресурсов мобильного приложения

## Необходимые файлы:

### 1. logo.png (512x512px)
- Логотип для экрана входа
- Можно скопировать из основного проекта: `public/logo.png`

### 2. icon.png (1024x1024px)
- Иконка приложения для магазинов
- Должна быть квадратной с прозрачным фоном

### 3. adaptive-icon.png (1024x1024px)
- Адаптивная иконка для Android
-Foreground (передний план) на прозрачном фоне

### 4. splash.png (1284x2778px)
- Заставка при запуске приложения
- Должна содержать логотип по центру

### 5. favicon.png (48x48px)
- Иконка для веб-версии

## Как добавить:

1. Создайте папку `assets/` в корне проекта
2. Добавьте все файлы из списка выше
3. Убедитесь, что имена файлов совпадают с указанными в `app.json`

## Быстрый способ:

Скопируйте логотип из основного проекта:
```bash
cp /path/to/web-app/public/logo.png assets/logo.png
```
