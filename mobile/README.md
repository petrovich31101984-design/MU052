# 📱 Мобильное приложение АлкоСпас для сотрудников

Полнофункциональное мобильное приложение для сотрудников выездной медицинской помощи, разработанное на React Native с использованием Expo.

## ✨ Возможности

### Основной функционал
- 🔐 **Авторизация** - вход по персональному номеру и паролю
- 🏥 **Управление сменами** - открытие/закрытие рабочей смены
- 📝 **Листы расхода** - создание листов расхода с выбором препаратов
- 💬 **Чат** - обмен сообщениями с руководителем
- 📢 **Объявления** - просмотр важных новостей
- 👤 **Профиль** - личная информация и настройки

### Технические особенности
- 📱 Кроссплатформенность (iOS + Android)
- 🔒 Безопасное хранение данных (Expo Secure Store)
- 🎨 Современный UI/UX дизайн
- ⚡ Быстрая навигация между экранами
- 🔄 Синхронизация с Google Sheets в реальном времени

## 🚀 Быстрый старт

### 1. Создание нового репозитория

```bash
# Создайте новый репозиторий на GitHub
# Например: alkospas-employee-mobile

# Клонируйте репозиторий
git clone https://github.com/your-username/alkospas-employee-mobile.git
cd alkospas-employee-mobile
```

### 2. Копирование файлов

Скопируйте все файлы из папки `mobile/` в корень нового репозитория:

```bash
# Если вы в корне текущего проекта
cp -r mobile/* /path/to/new-repo/
cp mobile/.gitignore /path/to/new-repo/
```

### 3. Установка зависимостей

```bash
npm install
```

### 4. Добавление ресурсов

Создайте папку `assets/` и добавьте:
- `logo.png` - логотип для экрана входа (512x512px)
- `icon.png` - иконка приложения (1024x1024px)
- `adaptive-icon.png` - адаптивная иконка для Android (1024x1024px)
- `splash.png` - заставка при запуске (1284x2778px)

Вы можете использовать логотип из основного проекта:
```bash
cp public/logo.png assets/
```

### 5. Настройка Apps Script

Откройте файл `APPS_SCRIPT_UPDATE.md` и следуйте инструкциям для добавления новых функций в Google Apps Script.

### 6. Запуск приложения

```bash
npm start
```

Отсканируйте QR-код в приложении **Expo Go** на вашем устройстве.

## 🔧 Технологии

- **React Native** - кроссплатформенная разработка

## 📱 Использование

### Первый запуск

1. Откройте приложение
2. Введите URL вашего Google Apps Script
3. Нажмите "Подключиться"
4. Введите персональный номер и пароль
5. Нажмите "Войти"

### Создание листа расхода

1. На главном экране нажмите "Лист расхода"
2. Заполните информацию о пациенте
3. Выберите категорию выезда
4. Добавьте препараты из номенклатуры
5. Укажите количество для каждого препарата
6. Нажмите "Создать лист расхода"

### Управление сменой

1. На главном экране виден статус смены
2. Нажмите "Открыть смену" или "Закрыть смену"
3. Статус обновится автоматически

### Чат с руководителем

1. Нажмите "Сообщения" на главном экране
2. Введите сообщение в поле ввода
3. Нажмите кнопку отправки (➤)
4. Сообщения синхронизируются в реальном времени

## 📦 Сборка для публикации

### Android APK

```bash
expo build:android -t apk
```

После сборки вы получите ссылку для скачивания APK файла.

### iOS (только macOS)

```bash
expo build:ios
```

Для публикации в App Store потребуется:
- Apple Developer Account ($99/год)
- Mac с Xcode
- Сертификаты и профили

### Публикация в Google Play

```bash
expo build:android -t app-bundle
```

Для публикации в Google Play потребуется:
- Google Play Developer Account ($25 единоразово)
- Подписанный AAB файл
